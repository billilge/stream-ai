# 정답요지 채점 기준 점검 (#51)

> 점검일: 2026-10-08
> 대상: `run-3fields`(2026-10-05, 프롬프트 v2) 답변. **답변은 새로 만들지 않고 채점만 다시 했다.**
> 그래서 아래 점수 차이는 전부 채점 방식 차이다.

## 왜 점검했나

PR #47에서 Recall@5가 87.5% → 100%가 됐는데 문서형 충족률은 39.1% → 37.0%로 제자리였다.
근거 문서를 다 찾아오는데 점수가 안 오르면 둘 중 하나다. 답변이 문서를 못 쓰거나, 채점이 못 재거나.

## 결론

**채점이 못 재고 있었다.** 낱말 비교 채점은 맞는 답을 틀렸다고 세는 쪽으로만 틀렸다.
틀린 답을 맞다고 센 경우(오탐)는 0건이고, 맞는 답을 놓친 경우가 15요지다.

| 같은 답변, 문서형 충족률 | 점수 |
| --- | --- |
| 낱말 비교 (지금까지) | 17/46 = **37.0%** |
| LLM 채점기 (이번에 도입) | 29/46 = **63.0%** |

| 채점 방식 | 기준 판정 75요지와 일치 | 두 번 돌려 같은 판정 |
| --- | --- | --- |
| 낱말 비교 | 60/75 = 80.0% | (결정적) |
| LLM 채점기 | 75/75 = 100.0% | 75/75 = 100.0% |

**지난 기록의 점수(21~39%)는 낮게 잰 값이다.** 프롬프트 v1/v2 비교처럼 같은 잣대로 잰 차이는 여전히 쓸 수 있지만,
절대 점수로 "답변 품질이 40% 수준"이라고 말하면 안 된다.

## 낱말 비교가 놓친 이유 4가지

| 원인 | 놓친 요지 | 예 |
| --- | --- | --- |
| 시각 표기 | 2 | 요지 `18:00` ↔ 답변 `18시`. 숫자 `00`이 답변에 없어 탈락 |
| 같은 뜻 다른 말·조사 | 8 | `별도 설치 없음` ↔ `따로 설치할 앱은 없어요`, `잔여석` ↔ `남은 자리`, `마감됨` ↔ `~까지예요` |
| 요지에 문서ID | 2 | `notice-8(9/18)부터 최신순`. 답변은 제목을 쓰지 문서ID를 쓰지 않는다. **영원히 못 맞힌다** |
| 행동 설명 요지 | 3 | `학점 수치 단정 금지`, `되묻기 또는 둘 다 안내`. 답변에 들어갈 낱말이 아니다 |

문서ID는 데이터를 고쳤다(`notice-*`·`LNK-*` 12곳 → 문서 제목). 나머지 셋은 낱말 비교로는 고칠 수 없다.
동의어 사전을 늘리는 방식은 끝이 없고, 행동 설명은 원리적으로 불가능하다. 그래서 채점기를 바꿨다.

## LLM 채점기

- 판정 기준: `prompts/judge_v1.md`. 뜻이 같으면 충족, **숫자는 값이 정확히 같아야** 충족, 일부만 있으면 미충족
- temperature 0, JSON 모양을 정해 받는다. 판정 개수가 요지 개수와 다르면 추측하지 않고 실패로 뺀다
- 판정 프롬프트의 예시는 골든셋에 없는 문장으로 썼다. 같은 문장이 들어가면 검증 점수가 부풀려진다
- 예전 방식은 `--grader rule`로 남겨 뒀다. 지난 기록과 비교할 때만 쓴다

## 이 검증의 한계 — 사람 검수가 필요하다

**기준 판정은 Claude가 답변을 하나씩 읽고 만든 것이다. 사람이 만든 것이 아니다.**
모델이 만든 기준으로 모델 채점기를 검증했으니 100%는 실제보다 좋게 나왔을 수 있다.
`eval/judge-labels.jsonl`에서 `검수필요`가 true인 **15요지**만 사람이 확인하면 된다.
낱말 비교와 판정이 갈린 곳이라, 나머지 60요지는 두 방식이 이미 같은 답을 냈다.

검수에서 뒤집히는 판정이 나오면 기준표를 고치고 `python eval.py --calibrate`를 다시 돌린다.
**채점기 일치율이 90% 아래로 떨어지면 판정 프롬프트를 고친다.**

대상은 문서형·문서형+실시간·학교공식·범위밖 75요지다. 실시간 41요지는 재고 조회 도구(#50)가 붙은 뒤 답변을 새로 만들고 검증한다.

## 채점을 고치고 보니 드러난 진짜 오답

채점 노이즈를 걷어내니 실제로 고쳐야 할 답변이 보인다. 6주차 "모르겠습니다 강화" 때 참고한다.

| 문항 | 문제 | 심각도 |
| --- | --- | --- |
| #46 `개총언제얌` | 9/4에 끝난 개강총회를 **앞으로 열리는 것처럼** 답했다(`열려요`). 기준시각은 9/19다 | 높음. 지난 행사 안내는 가장 흔한 사고다 |
| #30 `최근 3개 공지 띄워줘` | `찾지 못했어요`. 같은 뜻의 #29·#43은 답한다 | 중간 |
| #2·#11 | 신청 기간을 물었는데 일부 날짜를 빠뜨렸다 | 낮음 |
| #22 `빌릴게 물품 뭐 있어` | 재고를 몰라 화면에서 보라고 답했다 | #50 재고 도구로 해결 |

## 다시 재는 방법

```bash
python eval.py --calibrate                              # 채점기 검증
python eval.py --answers eval/run-3fields.json          # 저장된 답변을 새 채점기로
python eval.py --answers eval/run-3fields.json --grader rule   # 예전 방식
```
