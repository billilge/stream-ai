# 학교 AI 게이트웨이 모델 비교 (#61)

> 실행일: 2026-11-08
> 대상: 학교 AI 게이트웨이(`ai.cs.kookmin.ac.kr`, OpenAI 호환) 모델 + 현재 서버 모델 Gemini(`gemini-3.5-flash-lite`)
> 골든셋: `eval/golden.jsonl` 75문항(기준시각 2026-09-19), 프롬프트 v2
> 채점: 모든 모델을 같은 Gemini 채점기(`prompts/judge_v1.md`)로 판정했다. 채점기까지 바꾸면 점수 차이가 모델 때문인지 채점기 때문인지 가릴 수 없다

## 결론

- **문서 답변은 게이트웨이 상위 모델이 현재 Gemini보다 확실히 낫다.** sonnet·kimi·haiku는 3회 중 가장 낮은 점수(87~89%)도 Gemini(78%, 3회 모두 같음)보다 높다. 문서 답변은 골든셋에서 가장 큰 덩어리(25문항)다
- **정확도는 claude-sonnet-5-5와 kimi-k3가 공동 1위다.** 문서 답변의 범위가 89~93%로 같다. kimi는 출력 토큰이 sonnet의 약 3배라 더 느리고 토큰을 많이 쓴다
- **속도는 gpt-oss-120b가 가장 빠르고 안정적이다.** 평균 2.6초, 느린 쪽 10%도 4.1초다. 문서 답변은 87%로 sonnet보다 조금 낮다
- **glm-5는 제외한다.** 함정 거절이 70~90%로 크게 흔들렸고, 문서에 없는 링크를 지어낸 답변이 있었다

**최종 후보: claude-sonnet-5-5 (정확도 우선), 대안 gpt-oss-120b (속도·토큰 우선).**
어느 쪽으로 갈지는 모델별 토큰 차감 비율을 확인한 뒤 정한다(아래 "남은 확인").

## 진행 순서

1. 게이트웨이의 대화 모델 17개를 짧은 질문 2개로 걸렀다(1차)
2. 남은 7개를 골든셋 전체로 1회 비교했다(2차)
3. 상위 5개와 Gemini를 2회 더 돌려 점수가 흔들리는 폭을 쟀다(3차)

## 1차 — 걸러낸 모델

한국어 한 문장 답변과 도구 호출("지금 우산 남았어요?")만 확인했다. 챗봇은 재고 조회에 도구 호출이 필수라 못 부르면 바로 뺐다.

| 모델 | 뺀 이유 |
| --- | --- |
| nova-2-lite, nova-pro | 도구를 부르지 않는다 |
| gpt-6.1-sol | 이 게이트웨이 경로(`/v1/chat/completions`)에서 도구 호출을 거절한다 |
| devstral-2, mistral-large-3 | 한국어가 깨진다 |
| qwen3-coder, qwen3-coder-next | 코드 전용 모델이다 |
| claude-opus-5-5, grok-4.7, minimax-m2.5 | 토큰을 아끼려고 2차에서 뺐다. 탈락 사유가 있는 것은 아니다 |
| qwen3-embed | 대화 모델이 아니다(임베딩) |

## 3차 — 3회 평균 (괄호는 최저~최고)

금지 위반은 모든 모델이 0건이다. 오류는 sonnet의 시간 초과 1건(1회차)뿐이다.

### 칸별로 읽는 법

| 칸 | 챗봇이 하는 일 | 읽을 수 있는 것 |
| --- | --- | --- |
| 문서 답변 | 공지·행사 문서를 찾아 답한다 | **범위가 겹치지 않아 순위로 말할 수 있다.** sonnet·kimi > haiku ≥ gpt-oss > Gemini·glm |
| 실시간 조회 | 재고를 도구로 불러 답한다 | 모든 모델이 낮다. 모델 비교에 쓰지 않는다(아래 "한계") |
| 복합 질문 | 문서와 도구를 함께 쓴다 | 7문항이라 범위가 거의 겹친다. 순위로 말하지 않는다 |
| 학교 공식 안내 | 단정하지 않고 원문 링크로 보낸다 | 7문항이라 1문항이 10%p다. 순위로 말하지 않는다 |
| 함정 거절 | 모르면 모른다고 한다 | Gemini·sonnet이 조금 높지만 범위가 겹친다. glm만 흔들림이 크다 |

## 한계

- **실시간 조회 점수는 평가 쪽 문제로 보인다.** 골든셋은 2026-09-19 기준인데 재고 도구는 지금 시각과 가짜 응답(`tools.py`)을 돌려준다. 정답요지와 숫자가 어긋나 모든 모델이 15~29%에 머문다. 모델 문제라면 모델마다 차이가 나야 하는데 그렇지 않다
- **Gemini는 속도·토큰을 재지 않았다.** 기존 평가 경로(스트리밍)를 그대로 써서 기록하지 않았다. 정확도만 비교한다
- **채점기가 Gemini다.** Gemini 답변을 Gemini가 채점하므로 Gemini에 유리할 여지가 있다. 그런데도 문서 답변은 Gemini가 가장 낮았다
- **비용은 토큰 수로만 비교했다.** 게이트웨이에서 모델마다 토큰을 같은 비율로 차감하는지 모른다
- **링크를 지어내는 실수는 채점에서 걸러지지 않는다.** glm-5가 졸업요건 질문에 문서에 없는 링크(`kookmin.ac.kr`)를 붙였다. 지금 채점기는 정답요지와 금지 문구만 본다
